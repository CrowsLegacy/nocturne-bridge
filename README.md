# 🌙 Nocturne Bridge

**Official companion bridge for Nocturne by Crow's Legacy.**

Nocturne Bridge is a lightweight companion application designed to extend the media capabilities of the **Nocturne widget for CORSAIR iCUE and XENEON EDGE**.

It runs quietly in the background and provides the local connection required for Nocturne's enhanced media features.

---

## ✨ Features

- Enhanced media integration for Nocturne
- Runs quietly in the background
- Automatic startup with Windows
- Automatic recovery if the Bridge process stops unexpectedly
- Local communication with the Nocturne widget
- No separate Node.js installation required

---

## 📥 Installation

1. Go to **Releases**.
2. Download the latest `NocturneSetup-x.x.x.exe`.
3. Run the installer.
4. Follow the installation instructions.
5. Keep **Start Nocturne Bridge automatically with Windows** enabled for the best experience.
6. Open CORSAIR iCUE and launch Nocturne.

Once installed, Nocturne Bridge can start automatically with Windows, so you do not need to manually launch it every time.

---

## 💻 Requirements

- Windows 10 or Windows 11
- CORSAIR iCUE
- Nocturne

---

## 🔄 Updating

When a new version of Nocturne Bridge is available, download the latest installer from the **Releases** section and install it.

---

## 🛡️ Windows Security Notice

Nocturne Bridge is currently distributed without a commercial code-signing certificate.

Because of this, Windows may display an **Unknown Publisher** or Microsoft Defender SmartScreen warning when launching the installer.

Always download Nocturne Bridge from this official repository.
